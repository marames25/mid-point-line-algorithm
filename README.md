# Midpoint Line Algorithm

A C++ graphics project focused on implementing and demonstrating line-drawing algorithms.

## Description
This repository contains a Windows-based C++ application using a midpoint line algorithm and pixel-based rendering logic.

## Features
- midpoint line drawing
- support for varied line slopes
- pixel-based rendering
- Windows graphics application

## Technologies Used
- C++
- CMake
- Windows API

## Prerequisites
- CMake
- C++ compiler
- Windows OS

## Installation
```bash
cmake -S . -B build
cmake --build build
```

## How to Run
```bash
./build/computr_graphics
```

On Windows:
```powershell
.\build\computr_graphics.exe
```

## Project Structure
- `main.cpp`
- `CMakeLists.txt`

## Notes
The program uses Windows graphics API calls and is intended for a Windows development environment.
